# نموذج أولي لنظام إدارة المواقف

## التشغيل
1. ثبّت Node.js (يفضل إصدار LTS).
2. افتح مجلد المشروع في VS Code أو Terminal.
3. نفّذ:
   ```bash
   npm install
   npm run dev
   ```
4. افتح الرابط الذي يظهر في الطرفية، غالبًا http://localhost:5173

## الشاشات الموجودة
- لوحة التحكم.
- إدارة المركبات: تسجيل، بحث، تعديل، أرشفة بدل الحذف النهائي.
- ملف المركبة: بيانات اللوحة والشاسيه والموتور والمالك وكود الموقف وخطوط السير والمخالفات.
- إدارة خطوط السير والمحطات.
- تخصيص أكثر من خط سير للمركبة.
- المخالفات مع رقم المذكرة واختيار طريقة التسعير (لائحة/يدوي).
- التحصيل والتسويات كطلبات تحتاج مراجعة.
- التقارير، المستخدمون، الإعدادات وسجل العمليات.
- استيراد Excel/CSV مع معاينة قبل الإضافة.

## أعمدة Excel المقترحة
رقم اللوحة، المحافظة، رقم الشاسيه، رقم الموتور، اسم المالك، الرقم القومي للمالك، الهاتف، نوع المركبة، كود الموقف.
يمكن أيضًا استخدام أسماء الأعمدة الإنجليزية: plate, governorate, chassis, engine, owner, phone, type, code.

## مهم
- هذه نسخة Prototype للعرض والمناقشة فقط.
- كل البيانات المعروضة تجريبية، ولا يوجد Backend أو قاعدة بيانات أو تسجيل دخول فعلي.
- الاستيراد يقرأ ملف Excel داخل المتصفح ويضيف البيانات إلى حالة التطبيق مؤقتًا؛ لن تبقى بعد إعادة تحميل الصفحة.
- لا يتم تطبيق تسوية مالية أو تخفيض تلقائي. شاشة التسوية تمثل طلبًا للمراجعة فقط.
- أمثلة أنماط اللوحات والغرامات والأكواد الواردة من الحوار تحتاج تأكيدًا رسميًا قبل اعتمادها.
- حذف المركبة هنا عبارة عن أرشفة تجريبية مع الاحتفاظ بالسجل، وليس حذفًا فعليًا.
- استيراد 10,000 سجل في النسخة النهائية يحتاج API وBackend وقاعدة بيانات، وفحص التكرار وصحة البيانات على الخادم.
